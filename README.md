## 🚀 About

LexiProf is an educational platform designed to help STMG students learn, revise, and master their subjects through a modern, intuitive, and interactive experience.

Originally created by a former STMG student, the project aims to simplify revision while making learning more engaging and accessible.

This is not just a dictionary.

It is the foundation of a complete learning ecosystem.
